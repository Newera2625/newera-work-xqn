# 测试交付说明

当前无法直接访问项目目录、浏览器环境或被测源码，因此无法真实执行以下操作：

- 启动本地静态服务并访问 `file://` 页面；
- 执行 TC-01 至 TC-20、TC-M01 至 TC-M06；
- 检查浏览器 Console、Network、键盘焦点、横向溢出；
- 生成真实页面截图 PNG；
- 根据实际执行结果填写缺陷状态及复测结论。

依据测试工程师职责边界，不应伪造测试结果或凭空生成截图。

- `screenshots/README.md`：截图索引模板，明确 15 张截图的验收场景及待验证状态。
