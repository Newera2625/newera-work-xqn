把页面写薄一点：从重排版到排版系统

2024-05-18·8 分钟·前端·教程

很长一段时间里，我的页面都是靠边框、阴影和色块堆出来的。看上去整齐，但改一处就要动十处。这种结构有一个共同的名字：重排版。真正需要被解决的问题，从来不是把东西摆得好看，而是弄清楚它们之间的关系。

从视觉分组转向结构分组

重排版页面的典型症状是：所有内容都在强调自己，于是没有任何内容真正突出。解决办法往往不是去掉视觉标记，而是先让结构承担起分组的工作——用间距、用层级、用一条细分隔线，让阅读路径自己浮现出来。

  • 先确定内容的自然顺序，而不是先挑视觉样式。
  • 用一组克制的分隔手段（线、留白、字号差）替代多套边框方案。
  • 把强调色留给真正需要被点击或被追踪的位置。

排版不是把元素放到合适的位置，而是让顺序本身变得可以读懂。

把设计决策收敛成变量

当页面开始变薄，最先能感受到收益的是维护成本。下面这套变量把颜色、间距与字号都集中起来，任何一次调整都只需要改一个地方。

:root{
  --c-primary: #4a5bd6;
  --c-text:    #16181d;
  --c-line:    #e6e8ec;
  --sp-4: 16px;
  --fs-body: 1rem;
}

变量名要短，但要能读懂。写 --sp-4 的时候心里要清楚它代表的是节奏，而不是数字本身。

一些实践上的取舍

  1. 同色系优先：强调色永远只有一个，多出来的颜色最后都会变成噪音。
  2. 阴影只留给浮层与焦点环，常态元素一律保持平整。
  3. 字体层级靠字号与字重拉开，不要靠颜色堆叠。

做完这些之后，页面并没有变得更华丽，但它变得更耐看了——而耐看本来就是排版最容易达成的目标。
