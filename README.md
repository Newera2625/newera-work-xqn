# 个人博客站点 · 需求文档

## 一、目标

构建一个风格简洁现代的个人博客站点，包含 **首页 / 文章列表 / 文章详情 / 关于我** 四个页面，移动端与桌面端均可正常使用。内容以静态数据驱动，交互真实可用，不使用任何外部图片或 CDN 资源。

## 二、功能清单

1. **全站导航**：桌面端为顶部横向导航，logo + 三个链接（首页、文章、关于我）；当前页链接有高亮态。移动端（≤768px）折叠为汉堡按钮，点击展开下拉菜单，点击链接后自动收起。
2. **首页**
   - Hero 首屏：一句主标题 + 一句副标题 + 两个按钮（查看文章 / 关于我）。
   - 精选文章：3 篇文章卡片。
   - 最新文章：文章标题 + 日期 + 分类 + 摘要 的紧凑列表。
   - 页脚：版权、邮箱、社交链接（内联 SVG 图标）。
3. **文章列表页**
   - 全部文章卡片网格（6 篇以上）。
   - 分类筛选标签（全部 / 随笔 / 技术 / 设计 / 读书）。
   - 关键词搜索框，实时过滤标题与摘要。
   - 结果计数提示（如「共 6 篇文章」）。
   - 空结果时显示空状态提示与「清除筛选」按钮。
4. **文章详情页**
   - 通过 URL 参数 `?id=N` 读取文章数据，渲染标题、发布日期、分类、阅读时长、正文。
   - 正文含多级小标题，自动生成右侧/顶部目录，点击平滑滚动定位。
   - 上一篇 / 下一篇导航。
   - id 无效时显示「文章不存在或已被移除」提示 + 返回列表按钮。
5. **关于我**
   - 头像区（内联 SVG 生成的字母/图形头像，非外部图片）+ 个人简介段落。
   - 技能标签组。
   - 经历时间线（年份 + 角色 + 描述）。
   - 联系方式（邮箱、GitHub、Twitter 等文字链接）。
