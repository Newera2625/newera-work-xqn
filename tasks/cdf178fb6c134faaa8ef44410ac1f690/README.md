# 个人博客页面 · 需求文档

## 一、目标

制作一个可直接打开的个人博客主页（单文件 HTML + 本地 CSS/JS 组合），核心是以博主本人的 QQ 号 **3627236036** 作为身份标识，头像通过 QQ 官方头像接口实时获取（不硬编码图片），并配齐博客常见功能：文章列表、标签筛选、文章详情、主题切换、响应式布局。交付后提供桌面端与手机端截图预览。

## 二、功能清单

1. **QQ 头像模块**
   - 头像地址由 `https://q1.qlogo.cn/g?b=qq&nk=3627236036&s=640` 动态生成，QQ 号写死在配置处，只请求一次并复用到 Hero 大图与侧栏小图。
   - 头像为圆形，带 1px 主色描边环 + 柔和阴影。
   - 加载失败（onerror）或超时（3s）时，自动回退为内联 SVG 字母头像（背景为主色、首字母为白色），不出现破图。
2. **顶部导航**：Logo（博主名 + 一句 slogan）、锚点导航（首页 / 文章 / 标签 / 关于）、主题切换按钮；移动端折叠为汉堡菜单。
3. **Hero 首屏**：大头像 + 昵称 + 身份标签 + 一句话简介 + 主按钮（浏览文章）+ 次按钮（复制 QQ 号）+ 社交图标（GitHub / 邮箱 / QQ）。
4. **文章区**：文章卡片网格（封面纯色/渐变块 + 分类角标、标题、摘要、发布日期、阅读时长、标签），共 6 篇示例文章。
5. **标签筛选**：横向标签胶囊（全部 + 各标签），点击即时过滤文章并显示结果数量。
6. **文章详情抽屉**：点击卡片从右侧滑出抽屉，展示标题、日期、阅读时长、正文段落、标签、上一篇/下一篇；支持关闭按钮、点击遮罩、Esc 三种关闭方式，打开时锁定 body 滚动。
7. **侧栏**：关于我（头像 + 简介 + 站点统计：文章数 / 标签数 / 归档数）、标签云、归档年份列表、订阅 RSS 占位入口。
8. **关于区块**：单独的「关于」介绍区 + 技能/兴趣标签 + 联系方式。
9. **页脚**：版权信息、联系方式、回到顶部按钮。
10. **体验细节**：滚动时导航项高亮、回到顶部按钮（滚动 > 400px 出现）、主题切换写入 localStorage、hover/focus/active/disabled 状态齐全、`:focus-visible` 键盘可见焦点环。
