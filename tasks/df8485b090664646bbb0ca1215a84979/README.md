# 个人博客站点（单文件 HTML）需求文档

## 一、目标

制作一个可直接在浏览器打开的**单文件个人博客网页**（`index.html`），具备现代、克制、有设计感的个人主页形态：

- 顶部展示站长**个人头像**，头像**通过 QQ 号 3627236036 的公开头像接口实时获取**（无需上传、无需登录）。
- 站点包含博客核心功能：文章列表、文章详情、标签筛选、归档、关于我、联系方式。
- 纯静态、零依赖、零构建：双击 `index.html` 即可使用；桌面端与手机端都需完整可用。
- 不使用任何 emoji；图标全部使用内联 SVG 或纯 CSS 绘制。

## 二、交付物

| 文件 | 说明 |
| --- | --- |
| `index.html` | 唯一交付文件，内联全部 CSS/JS/SVG，`<head>` 内含完整样式与脚本 |
| `README.md` | 简短说明：如何修改文章数据、如何替换头像/联系方式、如何本地预览 |

不引入任何外部 JS/CSS 框架、不使用 CDN 字体、不引入外部图片资源（唯一外部请求为用户明确要求的 QQ 头像接口）。

## 三、功能清单

### 1. QQ 头像获取（核心）

- 头像源地址（固定使用 QQ 号 `3627236036`）：
  - 大图（页头）：`https://q1.qlogo.cn/g?b=qq&nk=3627236036&s=640`
  - 中图（侧栏/关于）：`https://q1.qlogo.cn/g?b=qq&nk=3627236036&s=100`
  - 小图（导航栏/列表条目）：`https://q1.qlogo.cn/g?b=qq&nk=3627236036&s=40`
- 图片统一加 `loading="lazy"`（页头首图除外，用 `loading="eager"` + `fetchpriority="high"`）、`referrerpolicy="no-referrer"`、`decoding="async"`。
- **降级方案（必须实现）**：给每个 `<img>` 加 `onerror` 处理，失败时隐藏图片并显示**本地内联 SVG 占位头像**（主色渐变圆角方/圆 + 站内昵称首字母），保证离线或接口失效时页面不出现破图。
- 头像容器为正方形，图片 `object-fit: cover`，加载时有骨架/呼吸微光占位（CSS 实现），图片淡入（opacity 过渡 0.3s）。

### 2. 页头 / 个人名片区（Hero）

- 左侧：QQ 头像（带 2px 主色描边 + 轻微投影）。
- 右侧：昵称（站点名）、一句话签名、所在地/职业等元信息一行、社交链接图标组（GitHub、邮箱、RSS、知乎等，纯内联 SVG 图标，链接可替换为真实地址，邮箱统一使用 `mailto:`）。
- 底部：主导航（首页 / 文章 / 归档 / 关于 / 联系我）+ 右侧**明暗主题切换按钮**。
- 向下滚动时页头收缩为吸顶窄条（仅保留头像小图 + 站点名 + 导航 + 主题按钮），使用 `position: sticky` + 滚动监听类名切换。

### 3. 文章列表

- 数据以 JS 数组 `ARTICLES` 定义在文件内，字段：`id / title / date / category / tags[] / excerpt / content(HTML 字符串) / readMinutes`。
- 内置 **6 篇示例文章**（内容为原创占位的中文技术随笔，真实可读，不得使用 lorem ipsum），至少覆盖 3 个分类、8 个标签。
- 列表以卡片形式展示：标题、日期、分类、标签、摘要、阅读时长；卡片有 hover 上浮 + 阴影加深过渡；点击整卡进入文章详情。
- 支持**标签筛选**：点击标签只显示该标签文章，筛选态有"当前筛选：xxx ×"的清除按钮；标签为胶囊样式，激活态使用主色实心。

### 4. 文章详情

- 通过 hash 路由实现（`#post/<id>`），无需服务器即可前进/后退、直接分享链接。
- 详情含：返回列表按钮、标题、元信息（日期/分类/阅读时长/标签）、正文（HTML，支持 h2/h3/p/ul/ol/blockquote/code/pre/表格/img 占位/inline svg 图表/链接）、文末"上一篇/下一篇"导航、相关文章（同标签最多 3 篇）。
- 正文排版：正文最大宽度约 68ch，行高 1.85，段间距 1.1em；`blockquote` 左侧主色竖线 + 浅主色底；`code` 等宽字体 + 浅灰底；`pre` 圆角深色块并支持横向滚动。

### 5. 归档

- 按年月分组展示文章（如 2025-03 / 2025-01），每条显示日期 + 标题；点击进入详情。空状态文案完整。

### 6. 关于我 / 联系我

- 关于：头像（100px）、个人介绍段落、技能标签、常用工具/技术栈小徽章（纯文字胶囊，不要图标库）。
- 联系：邮箱卡片、GitHub 等链接、以及一段社交说明；所有链接为真实可点击。

### 7. 页脚

- 版权年份（由 JS 自动取当前年）、"Built with HTML / CSS / JS" 说明、一行站点统计（文章数、标签数、最近更新日期）。

### 8. 全局交互与体验

- 明暗主题切换：基于 `prefers-color-scheme` 初始取值 + 手动切换，写入 `localStorage`（键名 `blog-theme`），持久化；两套配色均满足对比度（正文与背景 ≥ 4.5:1）。
- 所有可点击元素具备 `:hover` / `:focus-visible`（清晰焦点环）/ `:active` 状态；禁用态有样式。
- 移动端（≤ 768px）：单列布局，导航折叠为可展开菜单（汉堡按钮，纯 CSS/SVG 图形，不用 emoji），头像缩小，侧栏移到正文下方。
- 滚动到文章列表时触发渐入动画（`IntersectionObserver` + `prefers-reduced-motion` 时禁用）。
- 无 JS 时仍能通过 `noscript` 看到静态标题与说明（不出现空白页）。
- 浏览器兼容：Chrome / Edge / Firefox / Safari 最近两个大版本；ES6+ 语法即可，不使用需要构建的语法特性。

## 四、页面/模块结构

```
<body>
  ├─ header.site-header（sticky）
  │   ├─ .brand  [头像 img + SVG fallback] + 站点名 + 签名
  │   ├─ nav.site-nav（首页 / 文章 / 归档 / 关于 / 联系 + 主题切换按钮）
  │   └─ 移动端 .nav-toggle（SVG 汉堡）
  ├─ main
  │   ├─ section#home      → Hero 卡片 + 最新文章 3 条 + 标签云
  │   ├─ section#posts     → 工具栏（分类下拉 + 标签筛选 + 计数） + 文章卡片网格
  │   ├─ section#archive   → 年月分组列表
  │   ├─ section#about     → 头像 + 简介 + 技能标签 + 技术栈
  │   ├─ section#contact   → 邮箱/社交卡片
  │   └─ section#post      → 文章详情（hash 路由时显示，其余隐藏）
  └─ footer.site-footer（版权 + 统计）
```

| 变量 | 浅色值 | 深色值 | 用途 |
| --- | --- | --- | --- |
| `--c-primary` | `#33506B`（墨蓝） | `#8FB4D9` | 主色：链接、按钮、标签实心、焦点环、强调 |
| `--c-accent` | `#B06B4F`（陶土棕） | `#D99B7C` | 辅助色：仅用于小面积强调（归档年份、阅读时长点、hover 下划线），每屏出现不超过 3 处 |
| `--c-bg` | `#FBFAF8` | `#14171A` | 页面底色 |
| `--c-surface` | `#FFFFFF` | `#1C2024` | 卡片/面板 |
| `--c-text` | `#1F2428` | `#E6E9EC` | 正文 |
| `--c-text-soft` | `#6B7280` | `#9AA3AC` | 次要文字 |
| `--c-border` | `#E4E2DD` | `#2A2F34` | 描边/分隔 |

- 禁止出现红橙黄绿青蓝紫等彩虹配色；禁止高饱和渐变；仅允许主色→辅助色之间极低饱和度过渡（用于骨架微光）。
- 深色模式不是简单反色，需单独调整变量值，保持层级与对比。
