# 个人介绍网页 · 需求文档

## 一、项目概述

为 **小清** 制作一个介绍自己的单页 HTML 网站，作为个人名片 / 作品集首页。访客打开页面即可快速了解「小清」是谁、擅长什么、做过什么、如何联系。

- 交付形式：纯静态 HTML 页面（`index.html` + `style.css` + `app.js` 三个完整文件），双击即可在浏览器打开，无任何外部依赖。
- 技术约束：不使用任何外部图片、CDN、字体、框架；所有图形使用内联 SVG 或纯 CSS 绘制。

## 二、整体风格定位

| 项目 | 设定 |
| --- | --- |
| 主题气质 | 干净、清透、克制，带一点东方留白感 |
| 主色 | 青（`#2f7d72` 系，含深浅变体用于 hover / 描边） |
| 中性色 | 墨黑 `#1c1f1e` / 深灰 `#5b625f` / 浅灰 `#eef1ef` / 纸白 `#fbfcfb` |
| 辅助色 | 暖砂金 `#c08b4f`（仅用于小面积点缀，如分隔符、数字序号） |
| 字体 | 系统字体栈（`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`） |
| 禁止 | emoji、彩虹色、高饱和渐变、多色混用、外部资源 |

## 三、功能清单

1. **顶部固定导航栏**：Logo「小清 · Qing」+ 锚点链接（首页 / 关于 / 技能 / 作品 / 联系）+ 移动端汉堡菜单。
2. **首屏 Hero**：姓名大标题「小清」+ 一句话身份定位 + 两个行动按钮（查看作品 / 联系我）+ 右侧抽象内联 SVG 头像 / 视觉图形。
3. **关于我**：左栏头像与基本信息卡（所在地、方向、状态），右栏自我介绍段落 + 3 条快速事实（年份 / 项目 / 关键词）。
4. **技能展示**：4 个技能卡（图标 + 名称 + 熟练度进度条 + 一行说明）。
5. **作品 / 项目**：3 张项目卡（内联 SVG 封面缩略 + 标题 + 标签 + 简介 + 「查看详情」链接）。
6. **联系区**：联系方式列表（邮箱 / 微信 / 社交主页）+ 一个留言表单（姓名、邮箱、内容），前端校验并给出提交反馈。
7. **页脚**：版权、回到顶部按钮。

## 四、交互流程

1. 用户进入 → Hero 首屏立即呈现，滚动提示可见。
2. 点击导航锚点 → 平滑滚动至对应区块，当前区块对应的导航项高亮（scroll spy）。
3. 移动端点击汉堡 → 展开下拉菜单，选中后自动收起。
4. 滚动进度 → 页面顶部一条细进度条实时反映阅读进度。
5. 元素入场 → 各区块卡片随滚动淡入上移（IntersectionObserver，无 JS 时内容仍完整可见）。
6. 联系表单 → 提交时校验（姓名、邮箱、留言必填，邮箱格式），通过后显示成功提示并重置；不通过则逐项标红提示。
7. 悬停态 → 卡片轻微上浮 + 阴影加深；按钮有 hover / active / focus-visible 描边反馈；所有可点击元素支持键盘聚焦。
