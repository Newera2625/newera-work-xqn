# SSO 统一身份认证模块截图索引

## 1. 截图说明

本目录用于保存 SSO 统一身份认证模块的真实浏览器测试截图。

测试基准：

- 浏览器：Chromium 最新稳定版
- 桌面视口：1440 × 900
- 移动端视口：375 × 667
- 色彩空间：sRGB
- 页面缩放：100%
- 测试地址：本地静态服务器，例如 `http://127.0.0.1:8080`
- 执行原则：每条独立用例执行前清理 localStorage 和 sessionStorage
- 图片格式：PNG
- 命名规则：与下表“文件名”列完全一致

说明：

- “实际”栏必须根据截图中的真实页面状态填写。
- “结论”栏只允许填写“通过”“失败”或“阻塞”。
- 尚未执行时必须保持“待执行”和“待判定”，不得将模板视为测试通过。
- 页面存在横向滚动、文字截断、按钮遮挡、Console 报错或状态与预期不符时，应登记缺陷。

## 2. 测试钩子

前端实现应在 README.md 中公开以下测试参数：

| 参数 | 示例 | 用途 |
|---|---|---|
| `sessionSeconds` | `?sessionSeconds=60` | 缩短会话有效期，用于验证会话过期 |
| `lockSeconds` | `?lockSeconds=300` | 设置失败锁定时长 |
| `tab` | `?tab=sms` | 默认显示短信登录 |
| `tab` | `?tab=qr` | 默认显示扫码登录 |
| `qrState` | `?qrState=scanned` | 直接进入已扫描待确认状态 |
| `error` | `?error=password` | 注入密码错误状态 |
| `error` | `?error=locked` | 注入账号锁定状态 |
| `smsCountdown` | `?smsCountdown=60` | 直接进入短信倒计时状态 |
| `success` | `?success=1` | 注入登录成功状态 |
| `expired` | `?expired=1` | 直接注入已过期会话并展示模态框 |

生产环境如限制测试参数，应保证仅在本地或测试构建中启用，不得绕过真实认证策略。
