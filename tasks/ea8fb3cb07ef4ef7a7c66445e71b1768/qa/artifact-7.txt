
## 6. 人工复核清单

- [ ] 15 张必需 PNG 文件均存在且可以打开。
- [ ] PNG 像素尺寸与目标视口一致。
- [ ] 页面无横向滚动。
- [ ] 页面无文字截断或控件遮挡。
- [ ] 截图没有浏览器默认地址栏或操作系统遮挡。
- [ ] 登录表单输入项均关联 label。
- [ ] 错误提示使用 aria-live。
- [ ] 禁用按钮具有清晰视觉状态。
- [ ] 页面无 emoji 或表情符号。
- [ ] 页面无外链图片、字体或 CDN 资源。
- [ ] Console 无未处理异常和资源加载错误。
- [ ] 页面中所有图标均为内联 SVG 或 CSS 绘制。
- [ ] 配色符合单主色加中性色及辅助成功/错误色要求。
