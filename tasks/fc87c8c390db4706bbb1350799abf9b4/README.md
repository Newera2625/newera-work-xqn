# 个人介绍主页（HTML）需求文档

> 产出物：单文件 `index.html`（HTML + CSS + JS 全部内联，双击即可用浏览器打开，无需构建、无需联网框架）。

## 1. 目标

为用户（QQ：3627236036）制作一个**精美、可直接使用的个人介绍网页**，核心特征：

1. 页面主视觉位置展示**用户本人的头像**，头像**通过 QQ 公开头像接口按 QQ 号自动获取**（用户无需手动上传图片）。
2. 页面是一份完整的"个人名片 / 个人主页"，包含自我介绍、技能、作品、联系方式等要素。
3. 用户日后想改名字、简介、技能、联系方式时，**只需修改文件顶部一个 `CONFIG` 对象**，不必改动 HTML 结构。
4. 视觉现代、响应式、支持浅色/深色主题，桌面与手机都好看。

## 2. 头像获取方案（核心功能）

- 头像地址基于 QQ 官方头像 CDN：
  - 主源：`https://q1.qlogo.cn/g?b=qq&nk=3627236036&s=640`（高清 640）
  - 备用源 1：`https://q2.qlogo.cn/g?b=qq&nk=3627236036&s=640`
  - 备用源 2：`https://q1.qlogo.cn/g?b=qq&nk=3627236036&s=100`
  - 备用源 3：`https://qqqq.cn/mine?size=640`（第三方镜像，可选）
- 实现方式：`<img id="avatar">` 设置主源，`onerror` 事件自动按顺序切换到下一个源；全部失败时，回退到**内联 SVG 生成的字母头像**（用昵称首字/拼音首字母，渐变背景，不依赖任何外部图片）。
- 头像容器为圆形（`border-radius: 50%`），带**渐变描边光环 + 光晕阴影**，hover 时轻微放大；`loading="lazy"`（Hero 区可设 eager 优先加载），并设置 `referrerpolicy="no-referrer"`、`crossorigin` 不强制。
- 头像加载期间显示**骨架微光/脉冲占位**，加载完成后淡入（opacity 0→1，300ms）。
- 页脚与 Hero 中显示 QQ 号 `3627236036`，提供两个按钮：
  - "复制 QQ 号"：写入剪贴板并提示"已复制！"（使用 `navigator.clipboard.writeText`，失败时降级为 `document.execCommand('copy')`）。
  - "添加 QQ 好友"：跳转 `https://wpa.qq.com/msgrd?v=3&uin=3627236036&site=qq&menu=yes`（`target="_blank"`）。

## 3. 页面结构与模块

页面自上而下（单页 + 锚点导航，不做多页面）：

### 3.1 顶部导航栏（Sticky Header）
- 左侧：头像小圆图（同一 QQ 头像源，尺寸 40px）+ 昵称文字。
- 右侧：锚点链接「关于我 / 技能 / 作品 / 联系」，以及一个**主题切换按钮**（☀️ / 🌙 图标）。
- 滚动超过 80px 时导航栏获得毛玻璃背景 + 阴影；当前所在区块的导航项高亮（IntersectionObserver 监听 `data-section`）。

### 3.2 Hero 首屏
- 布局：左文右头像（≤768px 时上下堆叠，头像在上）。
- 左侧内容：
  - 问候语小标签（如「👋 你好，我是」）
  - **大标题昵称**（渐变文字）
  - **一句话个人简介**（副标题）
  - 3~4 个信息胶囊（标签）：如「Web 开发」「UI 设计」「持续学习」等，来自 CONFIG。
  - 两个主按钮：「联系我」「查看作品」（分别锚点跳转到联系/作品区）。
- 右侧内容：
  - QQ 头像（圆形大图，见第 2 节）
  - 头像下方悬浮小卡片：「QQ：3627236036」（带复制图标）。

### 3.3 关于我（About）
- 两栏布局：一段 2~3 行的自我介绍文本 + 右侧**信息卡片列表**（昵称、所在地、职位/身份、邮箱、QQ），卡片逐条淡入。

### 3.4 技能（Skills）
- 卡片网格（桌面 3 列 / 平板 2 列 / 手机 1 列）。
- 每张卡片：图标（Emoji 或内联 SVG）、技能名、熟练度进度条（渐变填充，进入视口时动画增长到目标百分比）、一句说明。
- 数据来自 `CONFIG.skills` 数组，字段：`{icon, name, level(0-100), desc}`。

### 3.5 作品（Projects）
- 响应式卡片网格（桌面 3 列 / 平板 2 列 / 手机 1 列）。
- 每张卡片：项目封面（**纯 CSS 渐变占位**，无外部图片依赖）、标题、简介、标签 2~3 个、「查看详情 / 访问」链接（`href` 可为空则不渲染）。
- 卡片 hover：上浮 6px、阴影加深、封面轻微缩放。

### 3.6 联系方式（Contact）
- 居中大卡片，包含：
  - QQ：`3627236036`（带一键复制）
  - 邮箱（来自 CONFIG）
  - 其他社交链接（GitHub / 博客 / 微信等，ICON + 文字，链接可配置）
- 底部一枚醒目的「复制我的 QQ」主按钮。

### 3.7 页脚
- 版权行 `© <当前年份> <昵称>. All Rights Reserved.`
- 一行小字说明：`头像通过 QQ 公开头像接口自动获取`（注明头像来源）。
- 可选回到顶部按钮（滚动平滑至顶部）。

## 4. 交互流程

1. 打开页面 → 导航栏与 Hero 立即渲染，昵称、简介等由 `CONFIG` 注入。
2. 头像开始异步请求 → 显示占位动画 → 成功淡入；若 3 个源全部失败 → 显示 SVG 字母头像，不出现破图。
3. 用户滚动页面 → 各区块元素按顺序淡入上移（IntersectionObserver，`.reveal` 类，触发一次）。
4. 点击导航锚点 → 平滑滚动到对应区块，并更新导航高亮。
5. 点击主题按钮 → 在 `light` / `dark` 间切换，写入 `localStorage`（键名 `theme`），刷新后保持；首次访问跟随 `prefers-color-scheme`。
6. 点击复制 QQ → 按钮文字变为「已复制 ✓」，1.5 秒后复原，并弹出轻提示 Toast。
7. 点击「添加 QQ 好友」→ 新标签页打开 QQ 加好友链接。

## 5. 视觉与风格

- **风格**：现代简约 + 渐变点缀；大圆角（卡片 16~20px，按钮 999px 胶囊）；柔和阴影；大量留白。
- **主色**：靛蓝/紫色系渐变（`#6366f1 → #a855f7 → #ec4899`），深色主题背景 `#0b1020` 系，浅色主题背景 `#f7f8fc` 系。
- **字体**：系统字体栈（`-apple-system, "PingFang SC", "Microsoft YaHei", "Segoe UI", Roboto, sans-serif`），不引用外网字体。
- **动效**：过渡时长 0.25~0.35s，缓动 `cubic-bezier(.22,1,.36,1)`；尊重 `prefers-reduced-motion`（开启时禁用动画）。
- **图标**：优先使用 Emoji；必要处使用内联 SVG（主题切换、复制、箭头）。不依赖 FontAwesome 等外部库。
