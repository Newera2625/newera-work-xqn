# 个人介绍网页（Personal Profile Page）需求文档

## 一、目标
制作一个**单文件 HTML 个人介绍网页**，用于展示用户本人的介绍信息。核心亮点：
1. 页面头部有个人头像，**通过 QQ 头像公开接口根据 QQ 号 `3627236036` 动态获取**（不使用本地图片文件），并在获取失败时自动降级为优雅的占位头像。
2. 包含个人简介、技能、项目、经历、联系方式等完整介绍结构，视觉精致、可直接用于分享。
3. 交付物为纯静态 HTML，**双击即可在浏览器打开**，不依赖任何构建工具、后端或 npm 安装。
4. 完成后使用浏览器打开该页面并截图，作为产品效果图交付。

## 三、头像获取方案（关键）
- **主地址（优先）**：`https://q2.qlogo.cn/gh/3627236036/3627236036/100`
  - 格式说明：`gh/<QQ号>/<QQ号>/<尺寸>`，尺寸可选 `40 / 100 / 640`。
- **备用地址（第一顺位失败时自动切换）**：`https://q1.qlogo.cn/g?b=qq&nk=3627236036&s=100`
- **最终兜底**：纯前端生成的 SVG 占位头像（`data:image/svg+xml`），底色取自主题渐变色，中间显示姓氏/首字母 "Q" 或 QQ 号后四位 `6036`，保证任何网络环境下页面都不出现"破图"。
- 实现要求：
  - 使用 `<img id="avatar">` 加载 `src`，绑定 `onerror` 事件，按"主 → 备 → SVG 占位"顺序降级，**最多重试 2 次**后使用占位。
  - 头像展示尺寸：Hero 区 140–160px 圆形；页面底部页脚处可再加一个 48px 小头像。
  - 圆形裁切（`border-radius: 50%`）+ 渐变描边 + 轻微阴影。
  - 不使用 canvas 绘制头像（避免跨域污染导致 `tainted` 报错），纯 `<img>` 引用即可。

## 四、功能清单
1. **顶部导航栏**：左侧 Logo/昵称，右侧锚点链接（关于 / 技能 / 项目 / 经历 / 联系），点击平滑滚动到对应区块，当前区块高亮（IntersectionObserver 或 scroll 监听）。
2. **Hero 首屏**：
   - 圆形 QQ 头像（动态获取，见第三节）
   - 姓名/昵称标题 + 一句话职业定位副标题
   - "联系我"（跳转到联系区块）与 "查看项目"两个主 CTA 按钮
   - 背景：渐变 + 网格/光斑装饰，鼠标跟随的柔和光晕效果（可选增强）
3. **关于我（About）**：2–3 段个人介绍文字 + 3–4 个数据卡片（如"工作年限 / 完成项目 / 擅长方向 / 城市"）。
4. **技能（Skills）**：3–4 组技能，每组为标签胶囊（chip）列表，可加进度条（百分比动画，滚动进入视口时触发）。
5. **项目（Projects）**：3 个项目卡片网格，含项目名、简介、技术栈标签、链接按钮（占位 `href="#"` 或真实链接）。
6. **经历（Timeline）**：竖向时间线，3–4 条经历，含时间、机构/职位、描述。
7. **联系方式（Contact）**：QQ 号 `3627236036`（可一键复制，复制成功提示 Toast）、邮箱、GitHub/个人主页等社交图标链接（SVG 内联图标）、QQ 一键加好友链接 `https://wpa.qq.com/msgrd?v=3&uin=3627236036&site=qq&menu=yes`。
8. **页脚（Footer）**：小头像 + 版权信息 `© 2026` + "Built with ❤"文案。

## 六、交互流程
1. 用户打开 `index.html` → 立即请求 QQ 头像（主地址）→ 成功则显示真实头像；失败 → 自动切换备用地址 → 再失败 → 显示 SVG 占位头像，全程无破图。
2. 点击导航锚点 → 页面平滑滚动到目标区块 → 导航对应项高亮。
3. 滚动到技能/项目区块 → 元素以淡入上移方式依次出现（IntersectionObserver，stagger 延迟 60–100ms），进度条宽度从 0 动画到目标值。
4. 点击"复制 QQ"按钮 → 调用 `navigator.clipboard.writeText('3627236036')`，失败时降级为隐藏 textarea + `document.execCommand('copy')` → 右下角弹出 Toast「已复制：3627236036」，2 秒后自动消失。
5. 鼠标在 Hero 区移动 → 背景光晕跟随移动（低性能设备可降级为静态）。
