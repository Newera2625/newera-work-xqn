# 产品截图交付需求文档

## 0. 需求解读与假设（重要）
用户仅提出「产品截图给我」，未指明产品、页面或使用场景。为避免反复确认造成阻塞，采用如下默认假设并直接执行：

- **假设 A**：用户想要的是「已实现产品/网页的界面实拍图」，而不是设计稿。因此交付物必须是**真实浏览器渲染出来的像素截图**，不是示意图、不是 Figma 导出稿。
- **假设 B**：若工作区中已存在可运行的前端/网页项目，则直接启动它并截图；若不存在，则先搭建一个**轻量演示页面**（足以展示产品界面质感）再截图。
- **假设 C**：交付形态为一组**按页面命名、可直接查看/下载的图片文件**，并在回复中附上简短说明（每个截图对应哪个页面、有什么内容）。

若上述假设与真实意图不符，用户后续只需一句话即可调整（例如「不是网页截图，我是要 XX 产品的宣传图」），届时按新意图重做。

## 1. 目标
1. 产出 **不少于 4 张**、覆盖产品核心界面的高保真截图。
2. 截图必须**真实可复现**：任何人按文档中的步骤执行，都能得到同样的画面。
3. 截图文件集中存放、命名规范、一眼可辨，交付时附带说明清单。

## 2. 功能清单
| 编号 | 功能 | 说明 |
|---|---|---|
| F1 | 环境与项目检查 | 检查工作区是否已有可运行项目（package.json / index.html / dist 等），判断走「截图既有项目」还是「新建演示页」路径 |
| F2 | 启动与本地服务 | 通过终端启动本地服务（优先 `npm run dev` / `npx serve` / `python3 -m http.server`），确认端口可访问、页面无报错 |
| F3 | 页面准备 | 确保截图对象包含完整的产品界面：导航栏/侧边栏、主内容区、数据或列表模块、按钮与表单等真实 UI 元素（不是纯色块或 Lorem 占位） |
| F4 | 浏览器截图 | 用浏览器技能打开各目标页面，等待字体与图片加载完成（网络空闲），按视口尺寸截取全屏图 |
| F5 | 多视口截图 | 至少提供桌面端（如 1440×900）一套；如演示页支持响应式，额外补一张移动端（如 390×844） |
| F6 | 文件归集与命名 | 截图保存到统一目录，文件名形如 `01-home-1440x900.png` |
| F7 | 交付说明 | 输出截图清单：文件名 → 对应页面 → 画面要点；并附访问方式（本地命令 + 端口），方便用户自行复现 |

## 3. 页面 / 模块（截图对象）
按顺序截取，每个都是独立图片文件：

1. **P1 首页 / 总览 Dashboard**：顶部导航、侧边栏、关键指标卡片（数据真实、不为空）、图表区。
2. **P2 列表页 / 数据表格**：含搜索框、筛选器、分页、至少 5 行真实数据，操作列有按钮。
3. **P3 详情页**：标题 + 元信息 + 主内容区块 + 侧栏信息。
4. **P4 表单 / 新建编辑页**：分组字段、标签、下拉/输入控件、主次按钮齐全。
5. **P5 移动端首页（可选，响应式成立时提供）**：390×844 竖屏截图。

## 4. 交互流程
1. 终端列目录 → 判断项目类型 → 决定路径 A（启动既有项目）或路径 B（新建演示页）。
2. 启动开发/静态服务 → 等待就绪 → 终端 curl 校验返回 200。
3. 浏览器打开根路径 → 控制台无报错 → 按 P1…P4 逐页导航并截图。
4. 切换到 390×844 视口 → 截取 P5。
5. 关闭服务进程 → 校验全部图片文件存在且体积 > 0。
6. 输出截图清单与复现步骤。

## 5. 验收标准
- [ ] 图片文件数量 ≥ 4，格式 PNG，无空白页、无加载失败图标、无未替换的 Lorem 文本。
- [ ] 每张截图分辨率符合目标视口（桌面 1440×900；移动 390×844）。
- [ ] 页面内文字、图表、表格均正常渲染，字体加载完成（无 fallback 抖动、无乱码）。
- [ ] 截图内容互不重复，分别对应 P1–P4（+P5）。
- [ ] 文件统一存放于 `screenshots/` 目录，命名规范可读。
- [ ] 交付说明包含：截图清单 + 本地启动命令 + 访问端口。
- [ ] 浏览器控制台无红色报错；本地服务可一键重启复现相同画面。

## 6. 约束
- **技术栈**：沿用项目现有技术栈；若无项目，演示页使用最轻方案（单 HTML + 内联 CSS/少量 JS，或轻量前端框架），不引入重量级依赖，保证秒级启动。
- **风格**：现代、简洁的 SaaS 后台风格；主色清晰，卡片带轻微阴影与圆角；深浅色任选但需统一；保证截图观感专业可用于对外展示。
- **数据**：使用真实可读的示例数据（中文业务语义，如订单、用户、金额），禁止 `TODO`/`xxx`/空白占位。
- **兼容性**：Chromium 内核浏览器；桌面优先；移动端截图需保证元素不重叠、不溢出。
- **安全**：不截图任何含真实密钥、身份证号、手机号明文等敏感信息的界面；示例数据需脱敏或虚构。
- **不涉及**：支付、登录鉴权、真实后端接口；截图相关页面不得依赖需要账号密码才能进入的路由。
- **技能使用**：仅使用终端、浏览器、图片、文件、代码相关技能，不调用未授权能力。

## 7. 交付物
1. `screenshots/` 目录下的 4–5 张 PNG 截图。
2. 一份截图说明（文件名 / 对应页面 / 画面要点 / 本地复现命令）。
