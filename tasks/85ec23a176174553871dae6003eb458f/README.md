## 四、页面/模块结构
```
<header class="site-header">  吸顶导航 + 汉堡 + 主题按钮
<main>
  <section id="home" class="hero">        头像 / 昵称 / QQ / 签名 / CTA
  <section id="posts" class="posts">      标签筛选 + 搜索 + 卡片网格 + 空态
  <article id="post-detail">              阅读视图（默认隐藏）
  <section id="about" class="about">      简介 / 社交 / QQ 复制 / 技能标签
</main>
<footer class="site-footer">              版权 / 签名 / 返回顶部
```
- 视图切换：`home/posts` 与 `post-detail` 之间切换时，隐藏列表、显示详情，并滚动到顶部。

## 五、交互流程
1. 打开页面 → 依次看到导航、Hero（含 QQ 头像）、文章列表。
2. 点击标签胶囊 → 列表即时过滤，激活胶囊变主色，计数更新。
3. 在搜索框输入关键词 → 列表即时过滤（大小写不敏感），无结果显示空态。
4. 点击「清空筛选」→ 恢复全部文章与默认标签。
5. 点击卡片 → 切换到详情视图，hash 更新，顶部出现进度条，滚动至顶部；点击「返回」或浏览器后退 → 回到列表并恢复筛选与滚动位置。
6. 详情页点击「上一篇/下一篇」→ 切换文章，hash 更新，滚动至顶部。
7. 点击「复制」复制 QQ 号 → 按钮文案变「已复制」，提示条出现后复原。
8. 点击主题按钮 → 全站配色即时切换并写入 localStorage。
9. 移动端点击汉堡 → 菜单展开，点击任意项 → 跳转对应区块并收起菜单。
