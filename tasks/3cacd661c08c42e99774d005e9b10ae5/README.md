# 个人博客首页（QQ 头像版）需求文档

## 一、目标
制作一个可直接双击打开的单文件 HTML 个人博客首页，作者信息以 QQ 号 `3627236036` 为身份标识，头像通过 QQ 官方头像接口动态获取（不下载、不入库），并在网络异常时提供内置兜底形象，保证任何环境下页面完整可用。交付物 = 1 个 `index.html` + 截图若干 + 说明文档。

## 三、页面/模块结构
```
<body>
  <header class="site-header">      导航 + Logo + CTA
  <main>
    <section id="home"    class="hero">      头像 / 昵称 / 简介 / 按钮 / QQ号
    <section id="posts"   class="posts">     文章列表 / 日志流
    <section id="projects" class="projects">  项目或文章与项目切换的卡片区
    <section id="about"   class="about">     自述 + 技能胶囊 + 社交
    <section id="contact" class="contact">   联系方式（邮件 / QQ）
  </main>
  <footer class="site-footer">     统计 / 版权 / 社交
</body>
```
- 所有样式内联于 `<style>`，行为用原生 `<script>`，无构建、无框架。
- 每个区块含 `.container`（最大宽 1120px 居中）与统一区块上下间距（96px 桌面 / 56px 移动）。

## 四、交互流程
1. **进入页面**：文档内无第三方脚本；QQ 头像立即请求加载；加载中头像容器显示主色浅色占位（骨架），成功替换为图片，失败依次切换备用源与内联 SVG。
2. **滚动**：导航当前项随视口所在区块高亮（IntersectionObserver 或 scroll 监听）。
3. **点击导航**：平滑滚动至目标区块，移动端先收起抽屉；URL hash 同步更新。
4. **点击 QQ 复制**：`navigator.clipboard.writeText('3627236036')`，成功 → 文案「已复制」+ 主色态，2s 后复原；失败 → 回退 `document.execCommand('copy')`，再失败提示「复制失败，请手动选择」。
5. **文章卡片 hover**：上移 2px + 阴影加深 + 标题变主色（0.2s ease）。
6. **加载更多**：追加 2 条文章，计数 +2，按钮在无更多数据时禁用并显示「没有更多了」（禁用态 opacity .45 + not-allowed）。
7. **主题/装饰图形**（若方案二含）：装饰图形为纯 CSS/SVG，hover 有轻微动效（≤8s 循环、prefers-reduced-motion 时关闭）。

## 五、视觉与代码约束（强制）
1. **禁止 emoji**：HTML 文案、注释、按钮文字中不得出现任何 emoji/表情；图标一律内联 SVG（描边风格、`currentColor` 着色）或纯 CSS 图形。
2. **配色克制**：仅 1 个主色（可用深浅变体）+ 中性色（黑/白/灰），最多 1 个辅助色；禁止红橙黄绿青蓝紫同屏，禁止高饱和彩虹渐变，禁止多色混用。
3. **CSS 变量统一**：`:root` 定义 `--color-primary`、`--color-bg`、`--color-text`、`--color-muted`、`--color-border`、`--color-surface`、间距 `--space-1..8`（8px 基准）、圆角 `--radius-sm/md/lg`、阴影 `--shadow-1/2`、字号 `--font-xs/sm/base/lg/xl/2xl`、字体栈；组件样式禁止硬编码颜色值（仅允许 `transparent` / `rgba(0,0,0,.x)` / 变量引用）。
4. **字体**：系统字体栈（`-apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`），代码/等宽文本用 `ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`；不加载 Google Fonts。
5. **无外部资源**：除用户指定的 QQ 头像接口外，不引用任何外部图片/CSS/JS/字体 CDN。
6. **真实感设计要求**：留白充足、层级分明（标题字重 700、辅助文字 13px 灰）、间距节奏统一、卡片圆角统一（12~16px）、阴影轻柔（低透明度多层），具备 hover/focus/active/disabled 状态，避免模板感与组件拼凑感。
7. **语义化标签**：header/main/section/article/nav/footer/button/a 正确使用，图片有 `alt`，图标按钮有 `aria-label`。

## 六、两版方案方向（供对比，主控择优或融合）
- **方案 A（UI-设计师A）· 暖调杂志排版**：浅色纸质底（暖白/米灰）+ 墨黑文字 + 单一暖橘主色；Hero 头像在左、文字在右；大标题排版感，卡片式文章区，侧栏式「关于我」。

- 两者必须共享：同一套功能清单 F1–F10、同一头像实现规范、同一无 emoji / 变量化 / 响应式约束。
- 融合规则：保留主色唯一性；最终版本需统一导航与页脚结构，取胜出方案的配色与列表形态，页面需有明确的「文章 / 关于 / 联系」三段式叙事。
