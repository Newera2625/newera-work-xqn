## 四、视觉与设计规范

- **配色**：主色为单一深靛蓝 `#2F5BEA`（含深浅变体：hover `#2447C4`、浅底 `#EEF2FF`），背景白 `#FFFFFF` / 深色模式 `#0F1115`，文字 `#111318` / `#E6E8EE`，中性灰阶 `#8A9099`、`#E4E7EC`。深色模式主色提亮为 `#6E8BFF`。除主色与灰阶外不使用其他彩色。
- **字体**：系统字体栈（`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`），不引入外部字体。
- **组件规范**：统一 CSS 变量（颜色、间距 8px 基数、圆角 12/16/999、阴影两级）；卡片 1px 边框 + 极淡阴影，hover 时上浮 4px 并加深阴影。
- **图标**：全部使用内联 SVG（QQ、邮件、GitHub、太阳/月亮、箭头、菜单），禁止 emoji。
- **头像**：通过 QQ 头像接口 `https://q1.qlogo.cn/g?b=qq&nk=3627236036&s=640` 拉取，`referrerpolicy="no-referrer"` 防止防盗链；`onerror` 时切换为内置 SVG 默认头像。

## 五、交互流程
1. 打开页面 → 导航固定在顶部，Hero 区头像异步加载（加载中显示浅灰占位）。
2. 点击导航锚点 → 平滑滚动到对应区块，导航项高亮更新。
3. 点击「主题切换」→ 深浅色即时切换并写入 localStorage，刷新后保持。
4. 填写留言并提交 → 表单校验（昵称与内容非空），无刷新追加到留言列表顶部，显示「提交成功」提示条。
5. 移动端点击汉堡 → 展开下拉菜单，点击项后自动
