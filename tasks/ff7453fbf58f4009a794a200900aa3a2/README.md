## 三、页面 / 模块结构

3. **头像区 `.avatar-wrap`**：
   - 外层光环（conic-gradient 渐变圆环，缓慢旋转 animation）

   - 加载骨架 `.avatar-skeleton`（与图片同尺寸绝对定位，图片 onload 后隐藏）
   - `onerror` 链式降级，最后使用内联 SVG data URI 占位图

4. **信息区 `.intro`**：
   - 标题 `<h1>`：默认文案 `QQ 3627236036`（作为昵称占位，注释说明如何替换为真实昵称）
   - 副标题 `.slogan`：`用代码记录热爱，用热爱奔赴山海`（占位文案，可改）
   - 简介 `.bio`：2–3 句占位文本，注明需替换为真实介绍
   - 标签墙 `.tags`：6–8 个 `.tag`（如 前端 / 后端 / UI设计 / 产品思维 / 摄影 / 音乐 等占位）
5. **联系方式区 `.contact`**：
   - 卡片：QQ 号 `3627236036` + "复制"按钮
   - 卡片：邮箱（占位 `hello@example.com` + 复制按钮，同 F6 逻辑）
   - 卡片：城市/坐标（占位文字）
6. **链接区 `.links`**：3 个链接卡片（图标占位用 emoji 或内联 SVG，标题 + 副标题）
7. **底部 `.footer`**：落款与年份（用 JS 取当前年份）
