# 个人博客站点 · 需求文档

## 一、目标

制作一套简洁现代的个人博客站点，包含首页、文章列表、文章详情、关于我四个页面，整体风格克制、留白充足、层级清晰，并在手机端提供完整可用的阅读与浏览体验。

## 二、功能清单

| 页面 | 文件 | 功能要点 |
| --- | --- | --- |
| 首页 | index.html | 顶部导航、Hero 首屏（标题 + 一句话简介 + 两个 CTA）、最新文章卡片区、精选文章、作者简介摘要、页脚 |
| 文章列表 | articles.html | 全量文章卡片、分类筛选、关键词搜索（实时）、空结果提示 |
| 文章详情 | article.html | 按 `?id=` 参数渲染文章标题/元信息/标签/正文、目录导航、阅读进度条、上一篇/下一篇 |
| 关于我 | about.html | 头像、简介、经历时间线、技能标签、联系方式 |

## 三、全局设计规范

- **配色**：单一主色（深靛蓝 `#2f4bff` 系，含深浅变体）+ 中性色（墨黑/白/灰），辅助色仅用于分类标签（柔和灰蓝）。全站不使用彩虹渐变。
- **字体**：系统字体栈（`-apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`），正文行高 1.75，正文最大宽度 720px。
- **组件语言**：统一 12px 圆角、`0 1px 2px rgba(16,24,40,.06)` 级别柔和阴影、1px 浅灰描边。
- **状态**：所有可点击元素具备 `hover` / `focus-visible` / `active` 状态，焦点环可见。
- **图标**：全部使用内联 SVG，不使用 emoji。
- **响应式**：断点 640px / 960px。手机端单列、汉堡菜单、无横向滚动。
