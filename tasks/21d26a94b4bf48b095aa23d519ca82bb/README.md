# 个人博客网站需求文档

## 一、项目目标

制作一个单用户、纯静态的个人博客网站，博客主人 QQ 号为 **3627236036**，网站头像通过 QQ 官方头像接口实时获取。整体风格为简洁、现代、偏技术极客风的个人博客，内容与排版专业可信，适配桌面与手机。

## 二、功能清单

| 模块 | 说明 |
| --- | --- |
| QQ 头像获取 | 使用 `https://q1.qlogo.cn/g?b=qq&nk=3627236036&s=640` 拉取头像，附带 `q2.qlogo.cn` 备用源；网络失败或图片加载出错时，自动降级为本地生成的 SVG 默认头像（灰色底 + QQ 号后四位 "6036"），页面不出现破图 |
| 顶部导航 | Logo（含小头像）+ 锚点导航（首页 / 文章 / 归档 / 关于）+ 右侧主题切换按钮（浅色 / 暗色） |
| Hero 首屏 | 大头像 + 昵称 + 一句话签名 + QQ 号展示 + 社交/联系按钮 + 向下滚动提示 |
| 文章列表 | 6 篇示例文章卡片：标题、日期、分类标签、摘要、阅读时长；支持按分类筛选（全部 / 前端 / 后端 / 生活 / 随笔） |
| 文章详情页 | 独立 `post.html`，含封面区（作者头像 + 昵称 + 日期 + 阅读时长）、正文排版（标题层级、引用、代码块、列表、表格）、目录锚点、上一篇/下一篇导航、返回首页按钮 |
| 关于我 | 个人简介、联系方式（QQ / 邮箱 / GitHub 风格链接）、技能标签、个人统计（文章数 / 字数 / 建站时间） |
| 归档 | 按年月分组的文章归档列表（锚点区块） |
| 页脚 | 版权、备案式信息行、回到顶部按钮 |
| 交互细节 | 滚动到视口的渐入动画、头像点击放大预览（遮罩弹层）、主题记忆（localStorage）、阅读进度条、hover / focus / active / disabled 状态齐全 |
